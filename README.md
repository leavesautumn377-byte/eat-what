# 今天吃什么

站在食堂门口，又不知道这一顿吃什么？把常吃的店和菜记下来，下次让它帮你挑。

这是一个给校园日常做的小工具：不用每天重新想一遍，也能慢慢留下自己的吃饭记录。

## 怎么用

1. 在「清单」里记下吃的名称、店名或食堂名，再选适合的时段和口味。
2. 在「选一顿」里直接抽，或者先选早饭、午饭、晚饭、夜宵与想吃的口味；不满意就点「换一个」。
3. 抽到想吃的，点「记这一顿」。照片、评价和文字都可以跳过；保存后在「记录」里查看。

初次打开会有一份校园餐食清单，你可以按自己的日常添加、修改或删除。口味标签支持多选。

## 安卓版

下载 [今天吃什么.apk](android-app/今天吃什么.apk)，安装到安卓手机即可体验。已有旧版时请直接覆盖安装；卸载旧版会清除保存在那台手机里的记录。

## 微信小程序

小程序源码在本仓库根目录。想在微信开发者工具中运行时，将 `project.config.example.json` 复制为 `project.config.json`，填入自己的 AppID，再导入整个项目并编译。

## 关于数据

清单、吃饭记录和照片保存在当前使用的设备上。安卓 App 和微信小程序的数据彼此独立，不会自动同步。卸载应用或清除应用数据可能丢失记录。

想了解安卓工程与源码构建方式，可看 [安卓开发说明](android-app/README.md)。本仓库暂未提供代码开源许可证。
