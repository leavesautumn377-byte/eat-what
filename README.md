# 今天吃什么

安卓测试版源码在 [android-app](android-app/README.md)。微信小程序仍是独立项目，安卓测试版不会读取或改动微信中的数据。

鸿蒙原生版正在 [harmony-app](harmony-app/README.md) 中开发，使用 ArkTS / ArkUI。目前尚待官方工具链编译、调试签名和设备验证，未生成可安装的鸿蒙测试包。该目录已从微信小程序上传范围中排除。

一个给大学生日常使用的微信小程序。记录平常吃的，再帮自己决定下一顿。安卓测试版和小程序共用浅绿水彩芭乐背景、浅绿纸片按钮与芭乐粉点缀。背景位于 `assets/watercolor-home.jpg`，界面字体采用霞鹜文楷的文字子集，许可见 `docs/OFL-wenkai.txt`。字体子集可用同版本的官方字体运行 `python scripts/rebuild-font-subset.py LXGWWenKai-Regular.ttf` 更新；用户自己输入的生僻字仍会回退到系统字体。

## 可以做什么

- 添加、修改、删除吃的，记录一个店名或食堂名。
- 点选早饭、午饭、晚饭、夜宵；一个食物可用于多个时段。
- 多选“养生”“重口”“碳水”“清爽”“热乎”等标签。
- 不筛选也能直接随机；“换一个”会在还有其他选择时避开当前结果。
- 随机本身不会记成吃过，点击“记这一顿”再保存。
- 照片、好吃/一般/不想再吃评价、文字都可选。
- 查看记录、点开照片、删除单条或清空记录。

同时选择多个标签时，只会抽取全部满足的食物。“不想再吃”只是一条评价，不影响后续随机。

## 在微信开发者工具运行

1. 下载本项目。
2. 将 `project.config.example.json` 复制为 `project.config.json`。
3. 在微信开发者工具导入这个目录，使用自己的 AppID。已有本地配置时无需覆盖。
4. 编译，首页为 `pages/index/index`。

原生小程序项目，没有运行时依赖，无需安装 npm 包。完整相机、相册和体验版测试请使用自己的小程序账号。

## 数据与照片

目前没有服务器、登录、广告或支付。每个人的清单、记录、照片仅在自己的设备里，不会自动同步给其他人或其他设备。

清除小程序数据、卸载、换机都可能导致数据丢失，目前没有备份与恢复功能。照片选好后，点击保存才会保存到小程序本地文件。保存失败会明确提示并保留表单，不会把临时照片当作已经长期保存。

首次运行附带 20 样校园餐食。升级到当前版本时，旧清单会先备份到本地，再一次性替换为这 20 样；吃饭记录和照片不会删除。之后自己添加或删除餐食，不会在每次启动时重置。清除应用数据仍可能丢失这些本地内容。

最新测试安装包是 [今天吃什么-仅20样清单-20261110.apk](android-app/今天吃什么-仅20样清单-20261110.apk)，仅供自己和同学测试。它尚未经过手机安装、拍照与相册实测；已有旧版时请直接覆盖安装，不要先卸载，以免丢失本地记录。

## 目录

- `pages/index`：筛选、随机、记录这一顿。
- `pages/wheel`：吃饭清单。为保留原有路径，目录名称暂未更改；当前没有圆形转盘动画。
- `pages/records`：历史记录与照片预览。
- `utils/storage.js`：本地数据兼容、读写。
- `utils/options.js`：时段、标签、筛选与随机规则。
- `utils/photos.js`：选图、本地保存、删除照片。
- `tests`：使用模拟微信接口的回归测试。

## 检查修改

安装 Node.js 18 或更高版本后运行 `npm test`。测试不需要安装依赖，也不会读取或修改手机中的真实数据。

手机实测步骤见 [使用检查](docs/manual-checks.md)。模拟测试不能代替微信开发者工具编译和手机相机测试。
