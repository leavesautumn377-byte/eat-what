# 手机使用检查

不要清理真实数据来测试。空清单等破坏性检查可用开发者工具的独立测试环境进行。

1. 首页不选时段、标签，直接点“帮我选”，应显示一个食物。
2. 选午饭，再同时选米饭、重口；两个标签都应高亮并有勾，结果应同时符合。
3. 点“清空标签”，标签恢复未选，时段保持。
4. 至少有两个可选食物时点“换一个”，不应立刻重复；仅一个时会提示放宽筛选。
5. 清单页添加名称、店名、多时段、多标签，保存后再修改，重开页面检查仍是修改后的内容。
6. 删除清单项时先取消一次，再确认。旧吃饭记录应继续保留。
7. 测试清单删空后切换页面、重启，不应重新出现示例；首页应引导添加。
8. 随机结果点“记这一顿”，拍一张照片；也分别试相册、取消选图、移除照片。
9. 不填照片、评分、文字也应可以保存；连续点保存只产生一条记录。
10. 保存含照片的记录，退出再打开，照片应可显示、点击预览。
11. 删除一条记录，其他记录及照片应保持；清空记录前先确认没有需要保留的真实数据。
12. 断网后试筛选、随机、记录，这些基础功能应仍能使用。

模拟测试覆盖逻辑和失败重试。相机/相册权限、隐私授权流程、基础库兼容、真实照片重启后显示，需要在手机上确认。提审时后台隐私说明应与实际功能一致。
