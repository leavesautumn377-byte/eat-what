# 安卓测试版

这是与微信小程序并存的独立安卓工程，不是微信小程序的打包文件。底部导航分为“选一顿 / 清单 / 记录”；抽取结果、记录表单、添加与修改表单各自单独打开，不再堆在同一页。无需登录或服务器，数据和照片只存在本机安卓 App 内。小程序数据不会自动迁移过来。

2026-11-10 的最新测试包是 `今天吃什么-仅20样清单-20261110.apk`。它基于 2026-11-09 的同包名、同调试签名 APK，替换当前工程的离线页面、样式与字体资源后重新对齐并签名，签名验证和资源哈希检查均通过；尚未在手机上安装实测。首次运行此版本时，旧清单会在本地备份后一次性替换为指定的 20 样餐食，吃饭记录与照片不删除。之后手动添加或删除餐食不会在每次启动时被重置。可直接覆盖安装同签名旧版，不要先卸载旧版，以免丢失本地记录。

## 在 Android Studio 生成测试安装包

已在本机命令行重新构建水彩版测试 APK：`今天吃什么-水彩测试版.apk`（版本 `0.5-meal-ticket-test`，原始构建文件在 `app/build/outputs/apk/debug/app-debug.apk`）。这台电脑没有连接安卓手机，**尚未完成手机安装与相机实测**。APK 包含离线背景图、字体和餐签咬痕启动图标；首页给背景上的手写句子留出了响应式空间。折纸图标版保存在 `今天吃什么-旧版v4-折纸.apk`，转盘图标仅保留为 `图标-转盘草稿.png`，未放入 APK。数据仍只保存在本机。

1. 如需自己重新构建，安装 Android Studio，打开本目录 `android-app`，让它安装所需的 Android SDK 35 和 Gradle。项目使用 Android Gradle Plugin 8.7.3，配套 Gradle 8.9 与 JDK 17。若 Android Studio 提示缺少 Gradle wrapper，可在安装 Gradle 8.9 后于本目录运行 `gradle wrapper --gradle-version 8.9`，再重新同步项目。
2. 在 Android Studio 选择 `Build > Build Bundle(s) / APK(s) > Build APK(s)`。
3. 构建成功后，测试 APK 通常位于 `app/build/outputs/apk/debug/app-debug.apk`。把它传到安卓手机上安装；系统可能询问是否允许从文件管理器安装应用。
4. 测试添加、修改、删除吃的，多选标签，抽一顿、换一个，拍照或选择照片，记录、删除记录。确认手机相机和相册都能打开。

Debug APK 仅供自己和同学测试，不是商店发布包。公开发布前需要设置正式包名、图标、隐私材料和稳定的签名密钥，再按目标应用商店要求审核。

## 当前限制

- 没有账号、云同步、微信小程序数据导入功能。卸载 App 或清除应用数据会丢失本机数据。
- 照片会压缩后保存在 App 的本地存储中；记录多了可能触及 WebView 存储容量限制。保存失败会提示，不会把记录误当成已保存。正式版应改为文件或数据库存储，并提供备份。
- APK 构建已通过，但尚未在真机上验证安装、相机和相册，具体兼容问题以手机测试结果为准。
