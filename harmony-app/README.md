# 今天吃什么 · 鸿蒙原生版

沿用水彩背景、霞鹜文楷和餐签咬痕图标，使用 ArkTS / ArkUI / Stage 模型实现。主入口为“选一个 / 清单 / 记录”，支持餐食编辑、时段与标签筛选、随机抽取、拍照/选图、可选评价与备注、历史记录统计和图片预览。

## 当前状态

本目录已写入原生源码和工程配置，正在准备官方工具链进行实际编译。**尚未生成可安装 HAP，也尚未验证真机运行。** 后续编译和设备验证结果会记录在此，不以现有微信/安卓测试结果替代。

本轮交付目标是可在用户设备安装的调试包，不包含应用市场审核提交。用户提供的设备信息为“华为 P90，鸿蒙 7”，实际型号、系统/API 和签名设备白名单待通过 HDC 核对。

## 工程

- `entry/src/main/ets/pages/Index.ets`：原生界面和交互状态。
- `entry/src/main/ets/model/MealData.ets`：筛选、抽取、数据模型与历史快照。
- `entry/src/main/ets/service/MealRepository.ets`：沙箱 JSON 数据及独立照片文件。
- `entry/src/main/ets/service/PhotoService.ets`：系统相册 Picker 和系统相机 Picker。
- `entry/src/main/resources`：原有背景、字体、图标；字体许可随包保留。

当前以官方稳定版 Command Line Tools / SDK 为构建环境目标。配置暂定目标 SDK API 26、兼容 API 17，实际配套关系需在工具链可用后编译确认。

## 数据

数据保存在应用自己的沙箱内，无登录、服务器、广告、支付或云同步。图库选图通过系统 Picker 取得指定文件；相机使用系统 Camera Picker。照片复制到独立文件后，记录只保存文件路径。JSON 通过先写临时文件再重命名的方式提交；读取损坏数据时显示错误，不自动用示例覆盖。

卸载或清除应用数据会丢失清单、历史和图片。微信版和安卓版的数据不会自动迁移。

## 业务规则测试

Node.js 22.13+ 或 24 环境执行：

```powershell
node --test tests/model.test.mjs tests/storage.test.mjs tests/resources.test.mjs
```

测试通过 Node 的 TypeScript 类型擦除执行业务模型及实际存储服务文件。模型测试验证筛选、快照、空清单、非法数据及输入边界；存储测试用 Node 文件接口适配器验证临时文件提交顺序、失败保留旧数据、图片所有权和文件句柄释放。它们不验证 ArkTS UI 编译、鸿蒙原生文件接口的实际行为、签名或设备安装。

2026-10-29：上述鸿蒙侧 21 项测试通过；与原微信/安卓 26 项测试一起运行，共 47 项通过。完整状态见 [VALIDATION.md](VALIDATION.md)。

## 调试签名与安装

1. 手机手动启用开发者模式和 USB 调试，连接电脑并允许调试。
2. 工具链就绪后通过 HDC 检查设备实际型号、系统/API 和连接状态。
3. 用户自行登录已实名认证的华为开发者账号，为此应用及该设备生成有效调试签名材料。
4. 签名配置和证书保留在本机私有目录，不进入源码仓库。
5. 构建签名 HAP，并实际安装运行；再核对冷启动、返回、照片重启后可用、删除和保存失败重试。

只有实际成功构建、签名并安装的文件才能标记为“可安装测试包”。
